# Harbor 1.0.0-rc.3

Harbor 1.0.0-rc.3 simplifies the ChatGPT experience around the latest Newsletter Intelligence report.

## Changed

- Replaced the multi-tab dashboard with one concise intelligence summary card.
- Moved detailed trends, content comparisons, audience signals, recommendations, and anomalies into ChatGPT's conversational response below the card.
- Adopted a white, system-sans-serif, grayscale presentation with thin dividers and no nested scrolling.
- Changed the UI resource URI so connected ChatGPT clients refresh the redesigned component.

This remains a release candidate. The deployed experience still requires live visual verification in ChatGPT before this candidate is tagged.
