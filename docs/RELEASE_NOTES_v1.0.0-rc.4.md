# Harbor 1.0.0-rc.4

Harbor 1.0.0-rc.4 establishes the compact visual pattern for Harbor's ChatGPT surfaces.

## Changed

- Added explicit internal row padding so content stays clear of the host card edge.
- Reduced the card heading to the Harbor name and a dynamically formatted intelligence report date at the same regular weight as the primary insight labels.
- Moved the report's narrative headline into ChatGPT's response below the card.
- Removed workspace, connection, timezone, section-label, and instructional footer clutter.
- Placed the three key metrics and three primary insights into aligned three-column rows.
- Matched insight labels to the body copy's size and weight, with supporting copy in gray.

This remains a release candidate pending visual confirmation of the live ChatGPT card.
